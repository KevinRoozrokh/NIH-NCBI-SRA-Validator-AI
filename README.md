# NIH-NCBI-SRA-Validator-AI

## 🧬 Understanding the NCBI SRA Validator AI

### The Application Concept

Think of this application as a **Flight Simulator for DNA Data** designed to optimize cloud operations for the world's largest biological databases. It acts as a pre-flight checklist and simulation engine for Technical Program Managers (TPMs) and Bioinformaticians.

### The Federal Ecosystem: NIH, NLM, and NCBI

  * The **National Institutes of Health (NIH)** is the primary U.S. federal agency for medical research.
  * Within the NIH lies the **National Library of Medicine (NLM)**, the world's largest biomedical library.
  * Operating under the NLM is the **National Center for Biotechnology Information (NCBI)**, which is responsible for hosting the massive databases that store the genetic blueprints of life.

### The SRA: Petabytes of DNA Data

The **Sequence Read Archive (SRA)** is the largest publicly available repository of high-throughput sequencing data. It stores raw DNA sequencing data generated by Next-Generation Sequencing (NGS) platforms like Illumina, PacBio, and Oxford Nanopore.

This database is measured in **Petabytes (PB)**—millions of Gigabytes. Managing this data requires massive cloud infrastructure (AWS STRIDES, Google Cloud Platform) and rigorous validation to ensure scientific integrity.

### The Challenge

Ingesting and validating genomic data at this scale is expensive and time-consuming. Running quality checks (like FASTQC) on a 10TB dataset can take days and cost thousands of dollars in cloud compute time. If a file is corrupted, discovering it *after* processing is a massive waste of resources.

-----

## ✨ Key Features: How This Tool Helps

This application leverages AI and simulation to streamline the SRA submission and validation process, allowing users to:

  * **Predict Cloud Costs:** Estimate storage and egress fees for major platforms like AWS S3 and Google BigQuery based on file size, enabling budget control before ingestion.
  * **Verify Data Integrity:** Simulate checksum verifications and header analysis to catch data corruption issues early, avoiding massive compute waste.
  * **Analyze Quality (Phred):** Visualize Q-Scores (Phred quality scores) to determine if raw DNA reads are accurate enough for scientific research.
  * **Bioinformatics AI:** Leverage the Gemini AI to generate customized Python validation scripts and answer complex technical questions related to genomic data formats and protocols.
  * **SRA Data Simulation:** Create synthetic but structurally accurate NCBI SRA metadata and sequence submission scenarios for comprehensive testing.

## 🚀 Run Locally

This project was generated from a Google Gemini AI Studio repository template and requires Node.js and a Gemini API key to run.

### Prerequisites

  * **Node.js** (LTS version recommended)
  * **Git**

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/KevinRoozrokh/NIH-NCBI-SRA-Validator-AI.git
    cd NIH-NCBI-SRA-Validator-AI
    ```

2.  **Install dependencies:**

    ```bash
    npm install
    ```

3.  **Configure API Key:**
    Create a file named `.env.local` in the root of the project directory and add your Gemini API key:

    ```
    # .env.local
    GEMINI_API_KEY="YOUR_GEMINI_API_KEY_HERE"
    ```

4.  **Run the application:**

    ```bash
    npm run dev
    ```

The application will now be running on `http://localhost:5173` (or a similar port displayed in your terminal).
